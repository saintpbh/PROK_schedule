간단한 1줄 설치

        

          워드프레스, 그누보드, 아임웹, 카페24 또는 순수 HTML 페이지 어디든 코드를 붙여넣기만 하면 바로 동작합니다.
        

      


      

        
2

        
완벽한 스타일 격리

        

          Shadow DOM 기술이 적용되어 외부 웹사이트의 기존 CSS나 글꼴 스타일과 전혀 충돌하지 않고 본연의 애플 감성을 유지합니다.
        

      


      

        
3

        
실시간 자동 동기화

        

          총회 본부에서 일정을 수정하거나 등록하면, 외부 사이트에 삽입된 위젯에서도 새로고침 없이 최신 일정으로 자동 반영됩니다.
